# نظام تسيير المحلات 🏪

نظام ويب متكامل لإدارة المحلات والمتاجر: المخزون، المبيعات، المشتريات، العملاء، الموردون، الموظفون، والتقارير.

## المميزات

- **لوحة تحكم** بإحصائيات فورية (مبيعات اليوم، أرباح الشهر، تنبيهات المخزون المنخفض)
- **نقطة بيع** سريعة مع إدارة السلة والخصم والضريبة وطرق الدفع
- **المخزون والمستودعات** مع حركات وارد/صادر/تسوية وتنبيهات الحد الأدنى
- **المبيعات والفواتير** مع مدفوعات جزئية وطباعة الفواتير
- **المشتريات والموردون** مع إدارة الديون والمدفوعات
- **العملاء** مع سجل المعاملات والذمم
- **الموظفون والصلاحيات** بأدوار مختلفة (مدير نظام، مدير عام، كاشير، أمين مستودع)
- **تقارير** بمخططات بيانية (المبيعات، الأرباح، أفضل المنتجات)
- **واجهة عربية (RTL) + إنجليزية** مع إمكانية التبديل الفوري

## التقنيات

- **الواجهة:** React + Vite + Recharts
- **الخادم:** Node.js + Express
- **قاعدة البيانات:** SQLite (ملف واحد، بدون إعداد)

## التشغيل

### مثل تطبيق مكتبي (الطريقة الموصى بها)
- يوجد اختصار **"نظام تسيير المحلات"** على سطح المكتب.
- انقر عليه مرتين وسيفتح المتصفح على `http://localhost:4000` **بدون أي نافذة أوامر (CMD)**.
- النظام يعمل كعملية واحدة في الخلفية بملف قاعدة بيانات محلي.

### للتطوير
```bash
npm install            # تثبيت الاعتماديات
npm run db:init        # إنشاء قاعدة البيانات والبيانات التجريبية
npm run dev            # تشغيل خادم التطوير + الواجهة معاً
```
- واجهة التطوير: `http://localhost:5173`
- الخادم: `http://localhost:4000/api`

### إعادة البناء بعد تعديل الواجهة
```bash
npm run build --workspace client
```
